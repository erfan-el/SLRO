# 🧩 Object Properties in the DM-KG

This document provides a detailed overview of the object properties defined in the Decision Mining Knowledge Graph (DM-KG) ontology.  
Each property includes its domain, range, description, and, where applicable, its inverse property and its corresponding description.  

---

| 2  | `causesProblem`          | `ProcessModelIssue`        | `DMProblem`           | An issue (e.g., invisible activity) causes a decision mining problem.                           | ✅         | `isCausedByIssue`        | A decision mining problem is caused by a specific process model issue.                       |
